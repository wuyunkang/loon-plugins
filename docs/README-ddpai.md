# 盯盯拍 Loon 去广告脚本

依据用户提供的 `500_1794621869199.zip` 抓包编写，日期为 2026-11-14。

## 安装

通过仓库首页的链接导入插件。插件会从本仓库加载脚本，无需手动导入 JS。开启 Loon 的脚本和 MitM（HTTPS 解密），安装并信任 Loon 证书，确认解密主机包含 `app.ddpai.com` 和 `appgw.ddpai.com`。完全退出应用后重新打开；已经缓存的广告可能仍会显示。

## 清理范围

| 接口 | 处理 |
| --- | --- |
| `/onroad/api/v1/ad/list` | 清空 `error_info.thirdAds`，涵盖抓包中标明的开屏、Banner、信息流、后台回前台广告位 |
| `/onroad/api/v2/banner/list` | 清空社区横幅列表 |
| `/market/api/v1/banner/list` | 清空商城横幅列表，保留版本等字段 |
| `/onroad/api/v1/activity/list`、`v2/activity/list` | 仅移除链接指向 `cdn.static.ddpai.com/h5/market/warranty/` 的延保推广，保留其他条目 |

HTTP、HTTPS 及抓包中的 `appgw.ddpai.com:18080` 均可匹配。只处理成功的 JSON 响应，保留错误码、版本及无关字段；失败响应、未知结构、非目标接口原样放行。不记录账号、设备或请求数据。

抓包中的第三方广告位 `status` 已为 `0`，脚本仍清空其下发配置；这不能证明所有广告都由该配置控制。`appRes/getMatchOne` 返回的视频用途尚不明确，未作拦截。设备连接、绑定、登录、录像、固件、订阅、商城购买以及本地设备网络均未加入规则；是否存在应用内部联动仍需手机实测。脚本不会隐藏原生商城/社区标签或强制去除广告占位，也不解锁付费功能。
